# Project history

The local research folder contains several exploratory generations of the
portfolio project. This GitHub edition uses **ETF Portfolio 4.0** as the
canonical implementation because it has the clearest four-stage pipeline,
validation logic, benchmark evaluation, and optional robustness appendix.

Four earlier iterations are preserved as curated snapshots under
`research-history/`. They document the progression from a hand-selected equity
portfolio to liquidity-screened ETFs, daily machine-learning forecasts, and a
minimum-correlation objective. Each snapshot emphasizes the evidence that
invalidated an assumption and motivated the next design.

The old folders also contain duplicated code, virtual environments, caches,
temporary test artifacts, superseded outputs, and large provider-data stores.
Those materials are intentionally not copied. Internal Word reports and
development logs also remain local rather than becoming part of the public
source distribution.

This curation changes only the GitHub-facing copy. The original local project
folder is not modified.
