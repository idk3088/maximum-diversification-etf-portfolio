# Project history

The local research folder contains several exploratory generations of the ETF
portfolio project. This GitHub edition uses **ETF Portfolio 4.0** as the
canonical implementation because it has the clearest four-stage pipeline,
validation logic, benchmark evaluation, and optional robustness appendix.

Earlier versions were useful during development but contain duplicated code,
virtual environments, caches, temporary test artifacts, and superseded output
files. They are intentionally not copied into this repository. Internal Word
reports and development logs also remain local rather than becoming part of the
public source distribution.

This curation changes only the GitHub-facing copy. The original local project
folder is not modified.
